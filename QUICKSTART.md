# 🚀 Быстрый старт - Система v3.0

## Первый запуск

### 1. Проверка установки

```bash
# Убедитесь, что вы в правильной директории
cd C:\Coding\ML\agro-robolife

# Активируйте виртуальное окружение
.venv\Scripts\activate

# Проверьте зависимости
pip install -r src\requirements.txt
```

### 2. Создание папок

Папки создаются автоматически при запуске, но можно создать вручную:

```powershell
New-Item -ItemType Directory -Force -Path shared_files,archived_files
```

### 3. Запуск сервера

```bash
python app.py
```

Вы должны увидеть:
```
INFO:     Uvicorn running on http://127.0.0.1:8000
INFO:     База данных инициализирована
INFO:     Планировщик отчетов запущен
```

### 4. Открыть в браузере

```
http://localhost:8000
```

## Первые шаги

### Шаг 1: Загрузить файлы
1. Перетащите Excel файлы в зону загрузки
2. Или нажмите "Загрузить файлы"

### Шаг 2: Настроить расписание

**Для ежедневного отчета:**
1. Выберите "Периодическая задача"
2. Установите время (например, 14:00)
3. Введите email
4. Нажмите "Установить расписание"

**Для разового отчета:**
1. Выберите "Разовая задача"
2. Выберите дату и время
3. Введите email
4. Нажмите "Установить расписание"

### Шаг 3: Получить отчет

**Вариант А: Дождаться**
- Система автоматически создаст отчет в указанное время
- Отчет будет отправлен на email
- Отчет появится в истории

**Вариант Б: Немедленно**
- Нажмите "Сгенерировать сейчас"
- Отчет создастся немедленно

## Настройка Email (опционально)

Создайте файл `.env` в корне проекта:

```env
SMTP_SERVER=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=your-email@mail.ru
SMTP_PASSWORD=your-app-password
SENDER_EMAIL=your-email@mail.ru
```

Протестируйте:
```bash
python test_email.py
```

## Типичные проблемы

### Порт 8000 занят

```bash
# Используйте другой порт
uvicorn app:app --port 8001
```

### База данных не создается

```bash
# Удалите и создайте заново
rm data/processing_history.db
python app.py
```

### Ошибка импорта модулей

```bash
# Переустановите зависимости
pip install -r src\requirements.txt --force-reinstall
```

## Доступ из локальной сети

Если нужен доступ с других компьютеров:

```bash
# Измените в app.py:
uvicorn.run(app, host="0.0.0.0", port=8000)

# Или запустите:
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

Теперь доступ по адресу: `http://YOUR_IP:8000`
