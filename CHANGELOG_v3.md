# Changelog v3.0 - Shared Files Architecture

## 🎉 Основные изменения

### ✨ Новые возможности

1. **Файловый менеджер** 
   - Общая папка файлов для всех пользователей
   - Drag & Drop загрузка файлов
   - Переименование файлов прямо в интерфейсе
   - Удаление файлов
   - Скачивание файлов

2. **Улучшенное расписание**
   - **Разовые задачи** - установить конкретную дату и время
   - **Периодические задачи** - ежедневная генерация отчетов в указанное время
   - Таймер обратного отсчета до генерации
   - Немедленная генерация отчета кнопкой

3. **Архивирование**
   - Автоматическое архивирование файлов при каждой генерации
   - Сохранение списка использованных файлов в отчете
   - Возможность отследить, какие файлы были в каждом отчете

4. **История отчетов**
   - Просмотр всех сгенерированных отчетов
   - Детальная статистика по каждому отчету
   - Список файлов, использованных для отчета
   - Скачивание любого отчета из истории

## 🔧 Технические изменения

### Новые модели
- `Report` - для хранения отчетов
- `ScheduleConfig` - для конфигурации расписания

### Новая структура папок
```
shared_files/         # Общая папка файлов
archived_files/       # Архив файлов по датам
outputs/              # Отчеты
```

### Новые API endpoints
- Управление файлами: `/api/files/*`
- Управление расписанием: `/api/schedule/*`
- История отчетов: `/api/reports/*`

## 📋 Что изменилось в использовании

### Было (v2.0):
1. Загрузить файлы
2. Обработать
3. Скачать результат
4. Повторить для следующего отчета

### Стало (v3.0):
1. **Один раз:** Загрузить все нужные файлы в общую папку
2. **Один раз:** Настроить расписание (разовое или периодическое)
3. **Автоматически:** Система генерирует отчеты по расписанию
4. **По желанию:** Добавлять/удалять файлы, скачивать отчеты

## 🚀 Преимущества новой архитектуры

1. **Удобство**: Не нужно загружать файлы каждый раз
2. **Автоматизация**: Настроил один раз - работает постоянно
3. **Общий доступ**: Все пользователи работают с одной папкой файлов
4. **История**: Все отчеты сохраняются и доступны для скачивания
5. **Гибкость**: Разовые и периодические задачи

## 📖 Примеры использования

### Пример 1: Ежедневный отчет
1. Загрузите все нужные файлы
2. Выберите "Периодическая задача"
3. Установите время "14:00"
4. Укажите email
5. Каждый день в 14:00 будет генерироваться и отправляться отчет

### Пример 2: Отчет на конкретную дату
1. Загрузите файлы
2. Выберите "Разовая задача"
3. Установите дату и время
4. Укажите email
5. В указанное время отчет будет отправлен

### Пример 3: Срочный отчет
1. Убедитесь, что файлы загружены
2. Настройте расписание с email
3. Нажмите "Сгенерировать сейчас"
4. Отчет создастся немедленно

## 🔄 Миграция с v2.0

Новая версия полностью заменяет старую архитектуру. Старые данные сохраняются в БД, но рекомендуется использовать новый интерфейс.

Подробнее см. `MIGRATION_GUIDE.md`

## 📝 Заметки

- Файлы в `shared_files/` НЕ удаляются после генерации отчета
- Архивные копии файлов сохраняются в `archived_files/{timestamp}/`
- Старые uploads папки можно очистить вручную
- Email настройки остались прежними (через `.env`)

## 🐛 Известные ограничения

- В локальной сети нет аутентификации (как и было запрошено)
- Размер загружаемых файлов ограничен настройками FastAPI
- Поддерживаются только .xlsx и .xls файлы
