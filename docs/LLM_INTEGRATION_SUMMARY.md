# LLM Integration - Краткая сводка

## 🎯 Цель проекта

Заменить жесткие парсеры Excel файлов на гибкий **LLM-based парсер**, который может обрабатывать файлы **любой структуры** без изменения кода.

---

## 📊 Ключевые показатели

| Метрика | Текущее состояние | Целевое значение |
|---------|-------------------|------------------|
| **Гибкость** | 2 жестких парсера | Любая структура |
| **Точность** | 100% для известных | 95-98% для любых |
| **Скорость** | Мгновенно | 2-5 сек/файл |
| **Стоимость** | $0 | ~$3-5/месяц |
| **Поддержка** | Код для каждого формата | Промпт-инженеринг |

---

## 🏗️ Архитектура

```
Excel → DataReader → LLMParser → Валидация → TableBuilder → Output
                         ↓
                    gptunnel API
                    (gpt-4o-mini)
```

### Основные компоненты

1. **LLMClient** - обертка над OpenAI SDK для работы с gptunnel API
2. **LLMParser** - извлечение данных через LLM в два этапа:
   - Анализ структуры файла
   - Извлечение данных
3. **Валидация** - Pydantic модели + бизнес-правила
4. **Кэширование** - экономия на повторных запросах

---

## 💰 Стоимость

### gpt-4o-mini тарифы
- Input: $0.15 / 1M токенов
- Output: $0.60 / 1M токенов

### Оценка на 1 файл
- Анализ структуры: ~2500 токенов → $0.0006
- Извлечение данных: ~7000 токенов → $0.002
- **Итого: ~$0.003 на файл**

### Месячная стоимость
- 1000 файлов/месяц: **~$3**
- С кэшированием (50% hit rate): **~$1.5**

## 🔄 Миграционная стратегия

### Фазы

1. **Parallel mode** (неделя 1)
   - Запуск обоих парсеров одновременно
   - Сравнение результатов
   - Валидация качества

2. **Gradual rollout** (неделя 2)
   - 25% файлов через LLM
   - 50% файлов через LLM
   - 75% файлов через LLM

3. **Full migration** (неделя 3)
   - 100% через LLM
   - Legacy парсеры как fallback
   - Мониторинг качества

4. **Cleanup** (неделя 4+)
   - Удаление старого кода (опционально)
   - Оптимизация промптов
   - Fine-tuning на основе feedback
