## 🎯 Основные функции

### 1. Файловый менеджер 📁
- Drag & drop загрузка
- Переименование файлов
- Удаление файлов
- Скачивание файлов
- Общий доступ для всех пользователей

### 2. Расписание ⏰
- **Разовые задачи** - отчет в конкретную дату/время
- **Периодические задачи** - ежедневные отчеты
- **Таймер** - показывает время до генерации
- **Немедленная генерация** - кнопка "Сгенерировать сейчас"

### 3. История отчетов 📊
- Все отчеты сохраняются
- Детальная статистика
- Список использованных файлов
- Скачивание любого отчета

## 🔥 Примеры использования

### Пример 1: Ежедневный отчет в 14:00
```
1. Загрузите все нужные файлы в систему
2. Выберите "Периодическая задача"
3. Установите время "14:00"
4. Введите email: boss@company.com
5. Нажмите "Установить расписание"

→ Теперь каждый день в 14:00 отчет будет генерироваться и отправляться!
```

### Пример 2: Срочный отчет прямо сейчас
```
1. Убедитесь, что нужные файлы загружены
2. Настройте расписание с email (если еще не настроено)
3. Нажмите "Сгенерировать сейчас"

→ Отчет создастся немедленно!
```

### Пример 3: Отчет на следующий понедельник
```
1. Загрузите файлы
2. Выберите "Разовая задача"
3. Установите дату и время (например, Понедельник 10:00)
4. Введите email
5. Нажмите "Установить расписание"

→ В указанное время отчет будет создан и отправлен!
```

## ⚙️ Настройка Email (опционально)

Если хотите автоматическую отправку на почту:

1. Создайте файл `.env` в корне проекта
2. Добавьте настройки:

```env
SMTP_SERVER=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=ваш-email@mail.ru
SMTP_PASSWORD=ваш-пароль-приложения
SENDER_EMAIL=ваш-email@mail.ru
```

3. Проверьте:
```bash
python test_email.py
```

**Без настройки email:** Отчеты будут генерироваться, но не отправляться. Вы сможете скачать их из истории.

## 📞 Если что-то не работает

### Сервер не запускается
```bash
# Проверьте, что установлены зависимости
pip install -r src\requirements.txt

# Проверьте, свободен ли порт 8000
# В PowerShell:
Get-NetTCPConnection -LocalPort 8000
```

### Файлы не загружаются
- Проверьте расширение (.xlsx или .xls)
- Проверьте права доступа к папке `shared_files/`

### Email не отправляется
- Проверьте настройки в `.env`
- Для Gmail используйте "Пароль приложения"
- Запустите `python test_email.py`

### База данных не работает
```bash
# Удалите БД и перезапустите
rm data/processing_history.db
python app.py
```
