# Руководство по миграции на новую архитектуру v3.0

## Что изменилось

Система была преобразована из модели "отдельная загрузка-отчет" в модель "общая папка файлов с периодической генерацией отчетов".

### Ключевые изменения:

1. **Общая папка файлов** (`shared_files/`) - все пользователи имеют доступ к одной папке с файлами
2. **Файловый менеджер** - возможность загружать, переименовывать и удалять файлы через веб-интерфейс
3. **Периодические отчеты** - поддержка как разовых, так и периодических (ежедневных) задач
4. **Архивирование** - файлы автоматически копируются в архив при генерации отчета
5. **История отчетов** - хранение всех сгенерированных отчетов с возможностью скачивания

## Новая структура папок

```
agro-robolife/
├── shared_files/              # Общая папка с файлами для всех пользователей
├── archived_files/            # Архив файлов по датам
│   └── YYYYMMDD_HHMMSS/      # Папка с файлами конкретного отчета
├── outputs/                   # Сгенерированные отчеты
└── templates/                 # Шаблоны Excel
```

## Новые модели базы данных

### Report
Хранение сгенерированных отчетов:
- `id`, `created_at` - идентификатор и время создания
- `output_file` - имя файла отчета
- `status` - статус (completed, sent, failed)
- `recipient_email`, `sent_at` - информация об отправке
- `archived_files` - список файлов, использованных для отчета
- Статистика: `records_count`, `departments_count`, `operations_count`, `crops_count`

### ScheduleConfig
Конфигурация расписания:
- `is_enabled` - активно ли расписание
- `schedule_type` - тип задачи (one_time / periodic)
- `scheduled_time` - время для разовой задачи
- `periodic_time` - время суток для периодической (формат "HH:MM")
- `recipient_email` - email для отправки
- `last_run` - время последнего запуска

## Новые API endpoints

### Управление файлами
- `GET /api/files` - список файлов
- `POST /api/files/upload` - загрузка файлов
- `DELETE /api/files/{filename}` - удаление файла
- `PUT /api/files/{filename}/rename` - переименование файла
- `GET /api/files/download/{filename}` - скачивание файла

### Управление расписанием
- `GET /api/schedule` - получить расписание
- `POST /api/schedule` - установить расписание
- `DELETE /api/schedule` - отменить расписание
- `GET /api/schedule/countdown` - время до генерации
- `POST /api/schedule/generate-now` - немедленная генерация

### Отчеты
- `GET /api/reports` - история отчетов
- `GET /api/reports/{id}/download` - скачать отчет
- `DELETE /api/reports/{id}` - удалить отчет

## Как работает новая система

### 1. Загрузка файлов
Пользователи загружают файлы в общую папку `shared_files/` через drag & drop или кнопку загрузки.

### 2. Настройка расписания
Пользователь настраивает:
- **Разовая задача**: указывает конкретную дату и время
- **Периодическая задача**: указывает время суток (отчет будет генерироваться ежедневно)
- Email для отправки отчета

### 3. Генерация отчета
При наступлении времени:
1. Все файлы из `shared_files/` копируются в `archived_files/{timestamp}/`
2. Файлы из архива обрабатываются
3. Генерируется отчет в `outputs/`
4. Отчет отправляется на email
5. Создается запись в таблице `Report`

### 4. Продолжение работы
- Файлы остаются в `shared_files/` для следующих отчетов
- Для периодической задачи процесс повторяется ежедневно
- Для разовой задачи расписание автоматически отключается

## Первый запуск

1. Убедитесь, что установлены все зависимости:
```bash
pip install -r src/requirements.txt
```

2. (Опционально) Настройте email в `.env`:
```env
SMTP_SERVER=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=your-email@mail.ru
SMTP_PASSWORD=your-app-password
SENDER_EMAIL=your-email@mail.ru
```

3. Запустите приложение:
```bash
python app.py
```

4. Откройте в браузере:
```
http://localhost:8000
```

## Использование

### Работа с файлами
1. Перетащите Excel файлы в зону загрузки или нажмите "Загрузить файлы"
2. Файлы появятся в таблице
3. Можно переименовывать, скачивать или удалять файлы

### Настройка расписания

**Разовая задача:**
1. Выберите "Разовая задача"
2. Укажите дату и время
3. Введите email
4. Нажмите "Установить расписание"

**Периодическая задача:**
1. Выберите "Периодическая задача (ежедневно)"
2. Укажите время (например, 14:00)
3. Введите email
4. Нажмите "Установить расписание"

### Просмотр отчетов
- Все сгенерированные отчеты отображаются в секции "История отчетов"
- Можно скачать отчет или просмотреть список файлов, которые были использованы

## Обратная совместимость

Старые модели и endpoints оставлены для совместимости, но помечены как устаревшие. Рекомендуется использовать новую архитектуру.

## Устранение проблем

### База данных не инициализируется
Удалите файл `data/processing_history.db` и перезапустите приложение.

### Ошибка отправки email
Проверьте настройки в `.env` файле. Для Gmail используйте "Пароль приложения", а не обычный пароль.

### Файлы не загружаются
Проверьте права доступа к папке `shared_files/` и убедитесь, что файлы имеют расширение .xlsx или .xls.
