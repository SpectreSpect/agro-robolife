# 🌾 Система обработки сельскохозяйственных данных

Модульная система для чтения, обработки и структурирования данных из Excel файлов с **веб-интерфейсом**, **Telegram ботом** и **автоматической отправкой по email**.

## ✨ Возможности

- 🌐 **Веб-интерфейс** - удобный интерфейс для загрузки и обработки файлов
- 📧 **Автоматическая отправка Email** - планирование отправки обработанных файлов на почту
- ⏰ **Планировщик задач** - указывайте время отправки и система отправит файл автоматически
- 🎛️ **Управление расписанием** - изменение времени, email, досрочная отправка или отмена
- ⏱️ **Таймер отправки** - видите сколько времени осталось до автоматической отправки
- 🤖 **Telegram бот** - обработка файлов прямо в мессенджере
- 📁 **Drag & Drop** - простая загрузка множественных файлов
- 📊 **История обработок** - хранение результатов с детальной статистикой
- ⬇️ **Скачивание результатов** - готовые Excel файлы с формулами и сводными таблицами
- 🖥️ **CLI режим** - классический режим работы через командную строку
- ⚡ **Быстрая обработка** - ~5 секунд на обработку файла

## 🚀 Быстрый старт

### 1. Установка (первый раз)

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация (Windows)
.venv\Scripts\activate

# Установка зависимостей
pip install -r src\requirements.txt
```

### 2. Настройка Email (опционально)

**Важно:** Система автоматически использует `certifi` для корректной работы SSL на удаленных серверах.

Для автоматической отправки файлов по email создайте файл `.env` в корне проекта:

**Для Mail.ru:**
```env
SMTP_SERVER=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=ваш-email@mail.ru
SMTP_PASSWORD=ваш-пароль-для-приложений
SENDER_EMAIL=ваш-email@mail.ru
```

**Для Gmail:**
```env
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=ваш-email@gmail.com
SMTP_PASSWORD=пароль-приложения
SENDER_EMAIL=ваш-email@gmail.com
```
Для Gmail создайте пароль приложения: https://myaccount.google.com/apppasswords

**Для Yandex:**
```env
SMTP_SERVER=smtp.yandex.ru
SMTP_PORT=465
```

**Тестирование настроек:**
```bash
python test_email.py
```

Тест автоматически:
- Установит `certifi` если его нет
- Проверит подключение к SMTP
- Покажет диагностику SSL сертификата
- Предложит отправить тестовое письмо

### 3. Запуск веб-интерфейса
```bash
# Windows - запуск через app.py
python app.py

# Или напрямую через uvicorn
cd src
uvicorn web.app:app --reload --host 127.0.0.1 --port 8000
```

### 4. Откройте браузер

Перейдите по адресу: **http://localhost:8000**

## 🤖 Telegram бот

1. **Создайте бота** у [@BotFather](https://t.me/BotFather) в Telegram


   ```bash

   ```

## 🎯 Использование

### Веб-интерфейс

#### Базовая обработка файлов
1. Откройте http://localhost:8000
2. Перетащите Excel файлы в зону загрузки
3. Нажмите "Обработать файлы"
4. Скачайте результат из истории

#### Обработка файлов
1. Загрузите Excel файлы
2. (Опционально) Отметьте галочку "Запланировать автоматическую отправку по email"
3. Если галочка отмечена:
   - Укажите время отправки (в вашем часовом поясе)
   - Укажите email получателя
4. Нажмите "Обработать файлы"
5. Файл обработается и:
   - Если email включен: автоматически отправится в указанное время
   - Если email выключен: просто будет доступен для скачивания

**Важно:** 
- Можно обрабатывать файлы БЕЗ отправки email - просто не ставьте галочку
- Все времена работают в вашем часовом поясе, не в UTC сервера
- В истории будет таймер обратного отсчета до отправки

#### Управление запланированными отправками

В истории обработок для каждой записи доступны действия:

- **📅 Запланировать отправку** - установить время и email для отправки
- **✏️ Изменить** - изменить время отправки или email получателя
- **🚀 Отправить сейчас** - отправить файл немедленно (отменяет запланированную отправку)
- **⏸️ Отменить отправку** - отменить автоматическую отправку
- **⬇️ Скачать файл** - загрузить файл вручную
- **🗑️ Удалить** - удалить запись и отменить отправку

Все действия требуют подтверждения с объяснением последствий.

3. Загрузите Excel файлы


Обрабатывает файлы из папки `data/` и создает результат в корне проекта.
