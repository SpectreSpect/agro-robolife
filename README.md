# 🌾 Система обработки сельскохозяйственных данных v3.0

Модульная система для чтения, обработки и структурирования данных из Excel файлов с **веб-интерфейсом**, **файловым менеджером** и **автоматической генерацией отчетов по расписанию**.

## ✨ Возможности v3.0

- 📁 **Файловый менеджер** - общая папка файлов с drag & drop загрузкой
- ✏️ **Управление файлами** - переименование, удаление, скачивание
- ⏰ **Гибкое расписание** - разовые и периодические (ежедневные) задачи
- 📧 **Автоматическая отправка Email** - настройте один раз, работает постоянно
- 🗄️ **Архивирование** - автоматическое сохранение файлов при каждом отчете
- 📊 **История отчетов** - все отчеты сохраняются и доступны для скачивания
- ⏱️ **Таймер обратного отсчета** - показывает время до следующей генерации
- 🌐 **Общий доступ** - все пользователи работают с одной папкой файлов
- 🚀 **Немедленная генерация** - создание отчета по требованию

## 🎯 Концепция

**Новая архитектура v3.0** кардинально отличается от предыдущих версий:

### Было (v1-v2):
```
Загрузка файлов → Обработка → Скачивание → Повторить
```

### Стало (v3.0):
```
Загрузить файлы один раз → Настроить расписание → Автоматическая генерация
```

Теперь не нужно загружать файлы каждый раз - просто добавьте их в общую папку, настройте расписание, и система будет автоматически генерировать отчеты!


Создайте файл `.env` в корне проекта:

**Для Mail.ru:**
```env

SMTP_PORT=465
SMTP_USER=ваш-email@mail.ru
SMTP_PASSWORD=ваш-пароль-для-приложений
SENDER_EMAIL=ваш-email@mail.ru
```

**Для Gmail:**
```env
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=ваш-email@gmail.com
SMTP_PASSWORD=пароль-приложения
SENDER_EMAIL=ваш-email@gmail.com
```

**Тестирование:**
```bash
python test_email.py
```

### 3. Запуск

```bash
python app.py
```

Откройте браузер: **http://localhost:8000**

## 📖 Руководство пользователя

### Работа с файлами

1. **Загрузка файлов**
   - Перетащите Excel файлы в зону загрузки
   - Или нажмите "Загрузить файлы" и выберите файлы
   - Файлы появятся в таблице файлового менеджера

2. **Управление файлами**
   - **✏️ Переименовать** - изменить имя файла
   - **⬇️ Скачать** - загрузить файл на компьютер
   - **🗑️ Удалить** - удалить файл из системы

### Настройка расписания

#### Разовая задача
Для генерации отчета в конкретное время:

1. Выберите "Разовая задача"
2. Укажите дату и время
3. Введите email получателя
4. Нажмите "Установить расписание"

**Пример:** Отчет нужен завтра в 15:00

#### Периодическая задача
Для ежедневной генерации отчетов:

1. Выберите "Периодическая задача (ежедневно)"
2. Укажите время (например, 14:00)
3. Введите email получателя
4. Нажмите "Установить расписание"

**Пример:** Каждый день в 14:00 отчет будет генерироваться и отправляться

## 🏗️ Архитектура

### Структура папок
```
agro-robolife/
├── shared_files/              # Общая папка файлов
├── archived_files/            # Архив по датам
│   └── YYYYMMDD_HHMMSS/      # Папка конкретного отчета
├── outputs/                   # Сгенерированные отчеты
├── templates/                 # Шаблоны Excel
└── src/
    ├── data_processing/       # Логика обработки
    └── web/                   # Веб-интерфейс
        ├── models.py          # Модели БД
        ├── report_scheduler.py # Планировщик
        └── templates/         # HTML шаблоны
```

### Процесс генерации отчета

1. **Архивирование**: Файлы из `shared_files/` копируются в `archived_files/{timestamp}/`
2. **Обработка**: Данные извлекаются из архивных файлов
3. **Генерация**: Создается Excel отчет в `outputs/`
4. **Отправка**: Отчет отправляется на email
5. **Сохранение**: Создается запись в таблице `Report`

### База данных

**Report** - хранение отчетов:
- Информация о создании и отправке
- Статистика обработки
- Список использованных файлов

**ScheduleConfig** - конфигурация расписания:
- Тип задачи (разовая/периодическая)
- Время генерации
- Email получателя

## 🔌 API Endpoints

### Управление файлами
- `GET /api/files` - список файлов
- `POST /api/files/upload` - загрузка
- `DELETE /api/files/{filename}` - удаление
- `PUT /api/files/{filename}/rename` - переименование
- `GET /api/files/download/{filename}` - скачивание

### Управление расписанием
- `GET /api/schedule` - получить расписание
- `POST /api/schedule` - установить расписание
- `DELETE /api/schedule` - отменить расписание
- `GET /api/schedule/countdown` - время до генерации
- `POST /api/schedule/generate-now` - немедленная генерация

### Отчеты
- `GET /api/reports` - история отчетов
- `GET /api/reports/{id}/download` - скачать отчет
- `DELETE /api/reports/{id}` - удалить отчет

## ❓ FAQ

**Q: Удаляются ли файлы после генерации отчета?**  
A: Нет, файлы остаются в `shared_files/`. Создается только архивная копия.

**Q: Можно ли иметь несколько расписаний?**  
A: Нет, активно может быть только одно расписание (разовое или периодическое).

**Q: Что делать если файлы изменились?**  
A: Просто обновите файлы в `shared_files/` - следующий отчет будет использовать актуальные данные.

**Q: Можно ли вручную скачать отчет?**  
A: Да, все отчеты доступны в разделе "История отчетов".

**Q: Работает ли система без настройки email?**  
A: Да, отчеты генерируются и сохраняются, но не отправляются на email.
